# Intern Springboard Project (intern-onboarding-springboard)

A simple JavaStack project for helping interns gain an understanding of the mechanics of SpringBoot

## Instructions for Developers

### Building the application

```shell
mvn clean package
```

### Start Application

IntelliJ should auto-detect the Spring Boot application and create a configuration for you.

* Select the `Application` run configuration, and then `Run` or `Debug`
* Use the `Services` tab to run or debug the application.

The application can also be started with the following command using a terminal from the root of the project.

```shell
cd webapp
mvn spring-boot:run
```

### Run Unit/Component Tests

An IntelliJ run configuration to execute all build-time tests is provided.

* Run `All Unit/Component Tests`

### Run Acceptance Tests

A run configuration for executing acceptance tests is also provided.

* Run `Application`
* Run `All Acceptance Tests`

For more information about running this project and tests, see the [HELP.md][help-md] file.
